# 安静小树重开发复盘

## 问题与来源

项目发起人在教育产品现场工作期间，听到一位班主任希望用小游戏实时感知课堂音量：安静得到奖励，嘈杂得到反馈。发起人曾借助 Codex 制作本地 HTML 版本，收到教师的积极定性反馈。此次没有提供旧源码，目标是重新实现一个可运行、温和、易维护、可公开开源的静态应用。

背景始终匿名；旧版反馈只属于旧版，不能作为此版本已经在课堂有效的证据。没有使用人数、降噪幅度或满意度数据。

## 实现与取舍

选择 Vite + TypeScript 原生组件和 SVG，没有前端运行时库。声音输入、状态引擎、校准器、偏好与视觉分开，演示和麦克风共用纯规则。三分钟有效安静换来果实；三秒先提醒、八秒才下垂，成长不回退，健康有下限且可恢复。这些均为本次设计假设。

使用数字相对音量而非真实分贝。五秒校准只生成建议阈值，不宣称专业声压校准。输入不录音、不上传、不转写，也不连接扬声器；暂停与后台释放输入以降低资源占用，继续由教师主动触发。

视觉围绕原创树木与自然色，大屏突出树，照料台集中设置。动效只解释成长、下垂与恢复，没有惊吓、闪烁或音效。为键盘、窄屏、减少动态和对比度偏好留出支持。

## 实际验证与修复

实际执行类型检查、30 项自动测试、普通与 Pages 模式构建；在可用浏览器中走通演示的安静成长、提醒、下垂、恢复与结果，检查暂停、重置、展示和三个屏幕尺寸。验证详情见 VALIDATION.md。

修复过测试 resolver 类型不匹配、较矮屏幕中树木位于首屏下方、演示回到真实输入的入口不足，以及音频启动取消的边界。补测晚到流和旧请求不能覆盖新输入，避免重复采集。

发布授权检查最初受沙箱网络限制影响，误显示 CLI 凭据无效；在允许网络的环境重新核验后确认授权有效，再检查同名仓库不存在并创建公开仓库。没有要求发起人重复授权，也没有将 token 写进项目。公开仓库已推送，首次 GitHub CI 与 Pages 部署成功，并实际打开 HTTPS 网站启动演示；链接与证据见 VALIDATION.md。

## 尚未证实

真实课堂效果、当前版本教师易用性、实际麦克风设备矩阵、系统级中断路径与全面无障碍仍待验证。开发演示和 mock 测试证明可操作机制与边界，不证明教学效果。

## 后续验证建议

先由教师在非正式课堂环境检查投影可读性和校准是否易懂，再试用不同教学活动。只记录经同意的匿名操作困难、误提醒情景与参数调整需求，不采集学生声音或个人资料。根据反馈修订默认参数，再考虑活动预设、多语言与树种扩展。

## 后续视觉与流畅度优化

发起人提出使用 Skill Finder、直接搜索 GitHub 并持续改善美观与流畅度。Codex 执行检索、阅读候选技能和三个类似项目源码，独立改造原创 SVG、连续成长与反馈说明，优化 DOM 更新，并修复实测的首帧/节流误暂停。测试由初版 30 项增加到 50 项。来源、实现取舍与验证边界见 RESEARCH_AND_POLISH.md 与 VALIDATION.md；本轮仍没有教师或真实课堂验证。

## 树种与奖励迭代（1.2）

发起人明确提出增加树种、每棵完整小树 2 金币和每种新树 120 金币。Codex 完成原创 SVG 树形扩展、独立奖励与收藏模型、商店交互、持久化、演示隔离与自动化边界测试。金币为本机共享课堂游戏奖励，没有学生个人积分、真实付款或排名；刷新仅保留钱包与偏好，不保留未完成轮次。实际检查与未验证部分继续记录于 VALIDATION.md。教师是否喜欢这一较长积累节奏，以及它对课堂专注的作用，仍待验证。
