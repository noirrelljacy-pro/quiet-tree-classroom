# 需求来源与范围

## 原始教师需求（由项目发起人转述）

在教育产品现场工作期间，一位班主任提出希望用小游戏实时感知课堂音量：安静时奖励，嘈杂时给予负向反馈，引导保持安静。项目发起人曾借助 Codex 制作本地 HTML 版本，收到教师关于好用的定性反馈。旧源码本次未提供，不推断旧版机制或量化成效；不公开学校、机构或教师身份。

## 本次新增设计

- 温和的树木生长、果实与可恢复下垂，短暂噪声不立即重罚，不清空成长。
- 浏览器本地相对音量、平滑、迟滞、持续时间缓冲；5 秒校准和三个可调参数。
- 真实输入与演示共用规则，明确标识演示，覆盖无权限/无设备情况。
- 暂停、结束、二次确认重置、下一轮、全屏/页面内课堂展示、后台冻结与资源释放。
- 原生 SVG 与柔和自然视觉、响应式、键盘和减少动态支持。
- 无后端、账号、排名、分析追踪或上传；本地偏好与本机收藏。
- Vite + TypeScript 分层源码、行为测试、中文文档、MIT 与 GitHub Actions/Pages 配置。

以上规则参数、界面和工程方案由 Codex 根据发起人的需求完成本次设计实现，不应归因于教师曾提出或认可这些具体细节。

## 验收重点

能从未开始进入真实采样或明确演示；安静→生长→结果可操作；持续嘈杂→提醒→下垂→安静恢复；暂停冻结；结束释放资源；校准可完成、跳过、取消；说明与实际实现一致。验证证据与未验证项单独记录于 VALIDATION.md。

## 未来设想（未实现）

教师试用后调整默认节奏、不同课堂活动预设、更完整多语言字典、更多主题、真实跨设备测试。任何将来数据分析或云同步均需重新评估隐私；第一版不包含学生账号、班级排名或个人积分。

## 发起人后续明确新增需求（1.2）

发起人要求多种树种、每完整种成一棵奖励 2 金币、每 120 金币解锁一种新树。Codex 据此设计五种原创树木、商店、默认免费香樟、独立演示钱包、本地持久化、防重复结算和跨标签页串行购买。这些为本次新增，不归因于最初教师需求，也没有教师试用结论。
