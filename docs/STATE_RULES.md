# 状态规则

所有时间均为前台有效运行时间，不使用墙钟补算；真实麦克风与演示输入经过同一平滑与状态引擎。

## 声音输入

麦克风时域数组 2048 个样本，RMS = sqrt(mean(sample²))。数字 RMS 对数映射为 `clamp(100 + 20 × log10(max(RMS, 0.00001)) × 100/60, 0, 100)`。这是自定义数字相对标度，不是声压分贝。演示滑块直接给出同标度模拟值。

两种输入均使用时间常数 0.3 秒的指数平滑 `previous + (input - previous) × (1 - exp(-dt/0.3))`。时序阈值针对平滑后的值，因此实际墙钟反馈会多一点输入稳定时间。

## 判定与状态

| 状态             | 条件                                        | 行为                                                        |
| ---------------- | ------------------------------------------- | ----------------------------------------------------------- |
| 未开始 idle      | 尚未运行或确认重置后                        | 显示幼苗，不推进                                            |
| 安静成长 growing | 平滑值不高于阈值且安静保持 2 秒、健康度为 1 | 每秒增加 1 / 成长目标秒数的进度                             |
| 噪声观察         | 超阈值但嘈杂计时不足 3 秒                   | 暂停成长，不损失健康和进度，显示“先等等看”                  |
| 温和提醒 warning | 嘈杂计时达到 3 秒、未到容忍时长             | 仅文字提醒，不下垂                                          |
| 枯萎 wilting     | 嘈杂计时达到容忍时长，默认 8 秒             | 每秒减少 1/16 健康度，最低 0.25；叶片转动下垂，成长永久保留 |
| 恢复 recovering  | 安静保持 2 秒且健康度低于 1                 | 每秒恢复 1/10 健康度，暂不成长；最坏约需 7.5 秒加 2 秒缓冲  |
| 结果 fruit       | 成长进度达到 1                              | 展示果实与祝贺、停止输入与计时；下一轮由教师手动开启        |

在健康的小树上，起始安静需要 2 秒缓冲，再累计 180 秒有效安静，默认约 182 秒结果。短暂噪声暂停成长，之后安静重新保持 2 秒再继续累计；健康未受损时不额外经过恢复。

迟滞：进入嘈杂需要 `level > threshold`；已经嘈杂后，需要 `level <= threshold - 4` 才视为安静。阈值边缘不频繁来回切换。短于 2 秒的安静间隔不会清除之前的嘈杂暴露时间（安静期间不增加嘈杂计时、不下垂）。因此“持续嘈杂”指未被至少 2 秒有效安静打断的嘈杂段，并非任意一帧低于阈值就重置。示例：2 秒噪声 + 1 秒安静 + 2 秒噪声会达到提醒，但一次 1 秒咳嗽不会下垂。

阶段：进度小于 25% 为幼苗，25% 起为小树，65% 起为成熟树，100% 结果。树干/冠幅随进度变化，健康度映射叶片角度与饱和度；默认没有循环摇摆、声音或闪烁。减少动态偏好下直接显示新状态。

## 会话控制

会话状态与树木状态分开：未开始 → 等待授权 → 校准 → 准备就绪 → 运行，可暂停、结束、结果。暂停/结束保留当前游戏状态并释放麦克风；继续重新申请输入。默认校准完不自动推进，教师确认开始。

每次只允许一个 requestAnimationFrame 链；暂停、结束、结果与页面离开取消它。单帧 dt 上限 0.25 秒，若间隔超过 1 秒，控制器直接暂停，防止设备休眠或任务阻塞产生突跳。后台恢复不自动重启。暂停会保留安静/嘈杂计时，恢复后接着计算；暂停期间不会产生奖励或惩罚。

操作序号用于丢弃过期启动；音频类另有代次标记。结束/切换模式时若旧权限请求稍后成功，该流也会立刻 stop；不建立第二套采样或循环。音轨 mute/ended、音频上下文中断会触发安全暂停。

确认重置将树木状态恢复到初始值、健康度恢复 1，设置保留，并停在暂停状态。取消确认不改变进度。结果后下一轮才增加轮次；刷新清除本轮状态。

## 校准与边界

5 秒前台采样，取排序后第 80 百分位样本加 10，再限制到 10–90，降低单次尖峰影响。不是专业声压校准；仅建议初始阈值。完成后显示具体阈值，可手调；跳过使用当前值，初次为默认 35。取消/后台切换丢弃未完成样本，阈值不变。演示不伪装成环境校准，重新校准仅对真实麦克风开放。

存储与滑块值统一经过 normalizeSettings：非数值或非有限数回落到默认值，合法数值取整并限制范围。调整目标时长保留百分比，新值只影响后续增长速度。修改阈值或容忍时长保留暴露计时，下次输入使用新设置；如需全新观察可重置本轮。
