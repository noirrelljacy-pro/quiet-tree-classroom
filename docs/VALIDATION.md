## 自动测试覆盖

- 安静 2 秒缓冲后成长；1 秒噪声不下垂且保留成长。
- 3 秒提醒，达到容忍时间才枯萎，长时间嘈杂有健康下限。
- 持续安静恢复健康，完全恢复后继续成长；短暂安静间隔不清除嘈杂暴露。
- 迟滞边界、暂停全部状态冻结、长帧限制、调整速度、结果终态与重置初值。
- 数字音量映射和平滑；非法设置和数值边界。
- 校准不足 5 秒不出结果、百分位与尖峰、极端阈值边界、异常输入与帧间隔。
- 流与 AudioContext 释放，幂等停止；授权拒绝清理；非安全来源与不支持浏览器的提示。
- 取消后晚到的流被停止；音频 resume 等待期间取消后不再请求流；旧请求不覆盖新的活跃流；设备结束、静音与上下文中断回调。

音频测试使用可控 mock，不构成真实麦克风兼容性证明。

## 浏览器已实际操作

- 下一轮、暂停/继续、结束；暂停在 30% 后多次观察保持 30%。
- 打开重置对话框默认聚焦取消；取消保留 30%，确认后归零且停在暂停状态。

2. 未完成 Chrome / Edge / Firefox / Safari、iPadOS、Android 的独立实机矩阵。内置浏览器全屏在测试 viewport override 下截图尺寸有差异，需在教室浏览器与投影屏复核原生全屏；页面内展示与退出已操作。
3. 后台与页面离开已实现主动释放、手动恢复；尚未逐一验证所有浏览器的休眠/BFCache/系统来电路径。长帧与取消竞态已单测。
4. 相对音量受设备、摆放位置、自动增益与环境影响，不能作专业声级测量或比较设备噪声。应校准并让教师调整。
5. 默认阈值与时长尚待教师验证；不能据此宣称改善课堂纪律、降低噪声或提高满意度。
6. 本轮状态不持久化；刷新从头开始。1.2 起仅保存偏好、本机金币、解锁树种与选择，无班级账号、学生个人积分、导出分析、多语言切换或离线 PWA。
7. 减少动态和增强对比样式已实现；屏幕阅读器、系统放大与无障碍全项审计仍待进行。

## 视觉与流畅度优化补记

本轮实际执行 Skill Finder 检索、类似 GitHub 项目源码阅读，来源见 RESEARCH_AND_POLISH.md。新增 20 个测试覆盖连续生长与阶段边界、反馈与短声平滑、相同输入 120 次不额外写入 DOM、首帧及节流/中断边界。类型检查、50 项测试、普通构建与 Pages 构建已通过。

浏览器实测发现 1.0001 秒帧调度导致旧版误暂停，已移除临时诊断输出，改为首帧锚定与 2.5 秒中断容差，并观察到正常继续成长。已实际点击短暂声音按钮，看到观察状态和舒展叶片，随后安静并达到 100% 果实。未测量或承诺稳定 FPS；中低端物理设备性能仍待验证。

终版 Pages 模式生产包使用 30 秒成长 / 4 秒容忍进行交互验收：持续嘈杂下垂后成长仍为 42%；暂停两次读取均为 42% 与 00:29；恢复安静后叶片旋转从 -45 度回到 0 度并继续成长至 66%。课堂展示隐藏教师面板并可退出，退出后设置和演示控件可用。手机 390px 与平板 768px 复核为单列且未横向溢出；桌面与矮屏也实际查看。原生全屏实机矩阵和减少动态系统偏好仍按已知限制保留。
